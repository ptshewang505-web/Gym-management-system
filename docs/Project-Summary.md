# GYM MANAGEMENT SYSTEM
### Initial Project Summary – Sprint 2

**Project Brief:** Project Brief 08  
**Project Domain:** Fitness & Health  
**Technology Stack:** MERN Stack (MongoDB, Express.js, React.js, Node.js)

## 1. Problem Statement

Many gyms still depend on manual registers and spreadsheets to manage members, trainers, attendance, membership plans and payments. These manual methods can result in inaccurate records, missed renewals, payment tracking errors and difficulties accessing updated information. Therefore, a centralized digital system is required to simplify and improve gym management operations.

## 2. Project Objective

The main objective is to develop a web-based Gym Management System using the MERN Stack that automates gym operations and provides efficient management of members, trainers, membership plans, attendance and payment records through a centralized platform.

## 3. Target Users

- **Administrator:** Manages members, trainers, membership plans, payments and reports.
- **Trainer:** Views assigned members and records attendance.
- **Member:** Views personal information, membership details, attendance history and payment status.

## 4. Core Modules

1. User Authentication and Role Management
2. Member Management
3. Trainer Management
4. Membership Plan Management
5. Attendance Management
6. Payment Management
7. Dashboard and Reports
8. Profile Management

## 5. Project Scope

**Included Features:**
- User login and role-based access.
- Member and trainer management.
- Membership plan management.
- Attendance tracking.
- Payment records.
- Dashboard and basic reports.
- User profile management.

**Excluded Features:**
- Dedicated mobile applications.
- AI-based fitness recommendations.
- Online payment gateway.
- Biometric attendance.
- Smartwatch integration.
- Live workout streaming.

## 6. Expected Outcome

The expected outcome is a centralized, user-friendly web application that reduces manual paperwork, improves record accuracy, simplifies gym administration, tracks attendance and payments, and provides organized access to gym information for administrators, trainers and members.

**Technology Stack:**
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Version Control: Git and GitHub
