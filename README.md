## Project Description
The Gym Management System is a web-based application designed to simplify gym operations by maintaining member records, trainer information, membership plans, attendance, and payment details. It provides administrators and trainers with tools to manage daily activities and allows members to view membership details and attendance records.

## Main Modules
1. User Management and Authentication
2. Member Management
3. Trainer Management
4. Membership Plan Management
5. Attendance Management
6. Payment Management and Reports
